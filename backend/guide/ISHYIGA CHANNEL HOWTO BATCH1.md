## Global Item Purchase Report in ISHYIGA ERP

Video: https://www.youtube.com/watch?v=wkl5mZvHTG4

View your purchase history by date range.

1. Open Ishyiga ERP MAIN GATE
2. Click on Purchases
3. Enter your credentials (ID and PWD)
4. Search Delivery
5. Select Global Item Purchases
6. Enter Date Interval (current month end / end date), then OK
7. The report shows item purchases with QTY PUR, QTY LIVE, AVERAGE PR, and Delivery/Livraison Count

## Sales Report in RRA FORMAT DETAIL via ERP

Video: https://www.youtube.com/watch?v=vHzCACSW9gM

## X AND Z REPORT IN ISHYIGA POS

Video: https://www.youtube.com/watch?v=zaWdEwZlkO4

1. Open POS MAINGATE
2. Login sales by entering your credentials
3. Click DATA, then REPORT
4. Select X REPORT
5. OPTIONS: MRC, then OK
6. Enter date
7. Choose ALL (or the shown option), then OK
8. Select Z REPORT if you want to view the report for a given period, then enter END TIME

## SAVE AND OPEN DRAFT IN ISHYIGA POS

Video: https://www.youtube.com/watch?v=U_0pptCopPs

Save a draft:

1. Select product (Enter qty)
2. Click DRAFT
3. Insert name of Client
4. Click OKEY

Open a draft:

1. Click DRAFT
2. SELECT OPEN DRAFT
3. CHECK WELL ALL PRODUCT (CLICK OKEY)
4. DOING FACTURE (click cash, enter total amount, choose client, click okey until sending facture)
