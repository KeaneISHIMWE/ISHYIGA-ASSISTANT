Conversation API

Live documentation for fetching Ishyiga WhatsApp chats

Open dashboard

Base URL


      
These endpoints are protected. Send the secret as Authorization: Bearer <CONVERSATIONS_API_KEY>. Traffic on Railway is HTTPS, so the key and chat data are encrypted in transit. Without the key, the API returns 401 and chats stay hidden.

      
Machine-readable spec: /api/openapi.json

    


    

      
API key

      
Ask Ishyiga for CONVERSATIONS_API_KEY. Put it here to try the live API, or send it in the request header.

      

        
      

      
Authorization: Bearer YOUR_KEY

      
You can also send X-Api-Key: YOUR_KEY. Do not put the key in the URL.

    


    

      
How to fetch chats

      
    
        
  1. Call GET /api/conversations with the API key to get the inbox.
    2. 
        
  2. Copy a conversation id.
    3. 
        
  3. Call GET /api/conversations/{id} with the same key to get every message in that chat.
    4.
